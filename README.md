# Internship Tracker

A web app for tracking internship applications. Add applications, filter by status, and keep notes. Data is saved in your browser.

**Live demo:** https://lisasolih.github.io/internship-tracker/

## Features
- Add, delete and filter applications
- Colour-coded status badges
- Live stats (total, interviews, offers)
- Date applied and notes per application
- Data persists using localStorage

## Built with
HTML, CSS and vanilla JavaScript
